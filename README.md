# Бриф на разработку сайта

Форма в духе [m-mukhanov.ru/brif](https://m-mukhanov.ru/brif): клиент заходит, заполняет и отправляет.

## Как запустить локально

Открой `index.html` в браузере или через Live Server.

## Отправка на почту

Форма уже настроена на `zhirkovakatya190517@gmail.com` через FormSubmit.

При первой отправке подтверди почту письмом от FormSubmit — после этого ответы будут приходить на email.

## Как выложить и дать ссылку клиенту

Варианты:

- **Tilda**: страница + HTML-блок (или собери похожую форму блоками Tilda и отправку на email)
- **Netlify Drop**: перетащи папку `brif` на [app.netlify.com/drop](https://app.netlify.com/drop) — получишь ссылку
- **GitHub Pages / Cloudflare Pages**

Клиенту кидаешь ссылку вида: `https://..../brif`
